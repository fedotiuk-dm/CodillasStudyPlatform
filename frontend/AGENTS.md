# frontend — agent contract

Next.js 16 (App Router) + React 19 client for the Codillas platform. Read this before editing.

## Stack

- **Next.js 16 / React 19**, TypeScript. **React Compiler** is on (`reactCompiler: true`) — do **not**
  hand-write `useMemo`/`useCallback`/`memo`; the compiler memoizes. Keep components pure.
- **shadcn/ui** (Radix + Tailwind 4) — `components/ui/*`. Add components with the shadcn CLI; style
  via the CSS variables in `styles/globals.css`. Icons: `lucide-react`.
- **TanStack Query 5 + axios**, client generated by **Orval** from `backend/openapi` (see below).
- **next-intl 4** for i18n; **keycloak-js** for auth; **@stomp/rx-stomp** for chat.
- Lint/format: **Biome** (`pnpm lint` / `pnpm format`). Package manager: **pnpm** only.

## Structure

```
app/[locale]/        Next routes (locale-prefixed). layout.tsx wires NextIntlClientProvider + RootProviders.
app/RootProviders.tsx  Theme + Query + Keycloak + Toaster, mounted once.
views/<area>/<view>/  Page-level compositions (the unit of work — see views/AGENTS.md).
components/ui/        shadcn primitives.   components/<feature>/  feature components.
lib/auth/            keycloak singleton + context + role hooks.
lib/api/<module>/    Orval-generated client (READ-ONLY) + model/ + zod/.
lib/services/axios-instance.ts  Orval mutator: JWT, refresh, FormData, error→logout.
lib/infrastructure/websocket/   RxStomp client + config.   lib/chat/  chat hooks.
lib/navigation.ts    Role-based sidebar config.   i18n/  next-intl routing/request/navigation.
messages/<locale>.json  Translations.   proxy.ts  next-intl middleware (Next 16 renamed it).
```

## Conventions

- **API-first.** `pnpm api` regenerates `lib/api/**` from `backend/openapi/*-paths.yaml`. Orval
  resolves the cross-file `$ref`s directly — **no bundling step**. Generated code is read-only;
  change the backend spec, regenerate. Every request goes through the axios mutator (one place for
  auth + serialization). Use the generated `useXxx` query/mutation hooks.
- **Invalidation is manual.** Orval does not auto-invalidate; it generates `getXxxQueryKey()`. After
  a mutation, `queryClient.invalidateQueries({ queryKey: getXxxQueryKey(...) })`. Centralize the
  resource→keys mapping when CRUD views need it.
- **Zod** is generated next to the client (`lib/api/<module>/zod/`) for `react-hook-form` resolvers.
  Disabled for read-only / live-messaging modules (gradebook, chat, notification) in `orval.config.ts`.
- **Auth.** `keycloak` is a singleton (one `init`). Read identity/roles via `useKeycloak`/`useRoles`/
  `useHasRole`. The JWT lives in memory (not a cookie) — server components can't read it, so role
  gating is client-side.
- **i18n.** Every page is under `/{locale}`. Use `useTranslations`/`getTranslations` and the i18n
  `Link`/`useRouter` from `@/i18n/navigation` (keeps the locale prefix). Locales: `uk` (default),
  `en`, `de`.
- **Chat.** `useChatRoom(roomId)` subscribes to `/topic/chat/{roomId}` and sends via STOMP; seed it
  with REST history from the generated hook.

```bash
pnpm dev          # dev server          pnpm api      # regenerate API client (orval)
pnpm build        # production build     pnpm lint     # biome check
pnpm typecheck    # tsc --noEmit         pnpm format   # biome format --write
```
